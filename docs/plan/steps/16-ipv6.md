# Step 16: IPv6 socket wiring

Status: pending (Linux, requires CAP_NET_RAW)

## Goal

Extend the raw send/receive paths to IPv6, reusing the IP-version-generic pipeline.

## Requirements

- `AF_INET6` `SOCK_RAW` sockets for send and receive, with the correct `IPV6_HDRINCL` semantics
  (noting kernel differences from IPv4).
- Surplus math uses IPv6 Payload Length minus extension headers (already in `IpRepr`).
- The receive pipeline and option handling are shared with IPv4 (no parallel code path).

## Plan

3. Root-gated `::1` round-trip with a surplus area, options, and FRAG.
